FONT
  Montserrat (free, Google Fonts). The wordmark itself is drawn as vector
  shapes; do not retype "SIMDA" in a font.
  In the .ai file the tagline is live Arial text so it opens on any computer;
  change it to Montserrat Bold if Montserrat is installed.
